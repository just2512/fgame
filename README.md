# 人生一程（fgame）

以《易经》的变化思想作为设计者的底层建模方法、以现代人生故事作为玩家体验的离线互动剧情游戏原型。

玩家只会看到人物、处境、矛盾、选择、剧情结果和人生感悟；卦、爻、吉凶及易学术语不进入玩家界面。运行时使用明确、可测试的规则，不进行起卦，也不调用 AI 生成剧情。

## 当前范围

v0.1 是一个垂直切片，不是完整商业版本：

- 核心设计规范：`docs/design/interactive-story-engine-v0.1.md`
- 剧情编写规范：`docs/design/story-authoring-guide.md`
- 样板故事：`docs/stories/sudden-billionaire.md`
- 可运行故事：`src/content/sudden-billionaire.json`
- 引擎：确定性状态更新、条件匹配、延迟后果、条件随机事件、结局匹配
- 界面：移动端优先的 HTML5 叙事界面
- 离线：Service Worker 缓存应用壳；存档写入 IndexedDB

首版只实现《突然成为百亿富二代》的第一阶段样板流程，用于验证规则模型。8–10 章完整故事、完整 8–12 个终局及更多人物视角不属于本次已完成范围。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

验证和构建：

```bash
npm run typecheck
npm run test
npm run build
npm run preview
```

首次访问需要加载静态资源；成功安装 Service Worker 后，应用壳与已缓存的资源可离线打开。首次离线安装不可能在完全没有网络的情况下完成。

## 操作

1. 打开游戏并开始新故事。
2. 阅读情境，选择你认为合适的处理方式。
3. 继续体验后续人物反应、延迟后果和偶发事件。
4. 到达本次样板流程结尾后查看人生结果。
5. 可重新开始；进度会自动保存在当前设备。

## 设计边界

- 易经只作为创作与建模方法，不是运行时占卜算法。
- 不存在系统认定的唯一正确选项；选项应具有收益、代价、条件和后续影响。
- 随机性只从人工编写且满足条件的事件中抽取，并由存档种子驱动。
- 相同版本、相同种子、相同选择序列必须得到相同结果。
- 不接入账号、服务器、广告或 AI 剧情生成。

## 当前验收状态

以仓库 CI 的类型检查、引擎单元测试和生产构建结果为准。真实 iPhone / Android 安装、桌面图标、离线启动和不同浏览器行为仍需在实体设备上验收。
