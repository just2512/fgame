# fgame 原型 v0.1 验收记录

## 范围

当前实现是《突然成为百亿富二代》第一章垂直切片，用于验证状态模型、确定性规则、延迟事件、条件随机事件、多个阶段性结果、IndexedDB 存档和 PWA 离线壳。

它不是完整 8–10 章剧情，也不是已完成真实设备验收的发布版。

### 5,000 局随机策略模拟结果

策略定义：每次从当前可用选项中等概率选择一个；剧情随机事件关闭，以单独的固定种子驱动选择策略；相同代码和种子可复现。该分布用于发现不可达或明显垄断的结局，不等于真实玩家偏好或理想平衡目标。

| 阶段性结局 | 局数 | 占比 |
|---|---:|---:|
| 你开始真正掌舵 | 293 | 5.86% |
| 财富之外的伙伴 | 1,182 | 23.64% |
| 你选择另一种人生 | 968 | 19.36% |
| 被关系牵住的继承人 | 386 | 7.72% |
| 故事才刚刚开始 | 2,171 | 43.42% |

本次没有结局低于 1% 或高于 60% 的异常值。开放结局占比最高，后续需用真实试玩记录判断是否需要提高专用结局的叙事与条件覆盖。

## 已知边界

- 浏览器首次加载或 PWA 首次安装需要网络；Service Worker 激活并缓存资源后，才可验证离线启动。
- 当前 PWA 图标为 SVG 占位图，iOS 桌面图标仍需实体设备核验；如显示不符合预期，再补专用 PNG 图标。
- 当前只有单一故事和第一章流程；5,000 局仅覆盖本章均匀随机选择策略，不代表激进、保守和摇摆玩家的真实行为分布。
- 目前用单元测试验证关键引擎规则，不将其等同于剧情质量或用户体验验收。
