# 样板故事：《突然成为百亿富二代》

- 版本：v0.1 第一章垂直切片
- 风格：现代都市、轻松克制，允许少量幽默，不讽刺普通人的困境。
- 玩家身份：原本是普通职员，意外继承家族巨额资产。
- 核心矛盾：资产继承不等于企业控制权；财富增加不代表能力、信任和关系同步增加。

## 开场

周一上午，你正在公司会议室里听主管讲季度目标。手机连续震动了三次。

一个陌生号码打来，对方自称是家族律师，告诉你祖父昨夜去世，遗嘱确认你将继承家族主要资产。

你以为是诈骗。直到下午，律师把文件放到你面前。资产规模远超你的想象，但家族企业的董事长仍是你的叔叔，经营团队也由他掌握。

你突然拥有了很多东西，却不知道第一步该做什么。

## 第一章：继承之初

### 场景 1：遗嘱宣读后的第三天

叔叔在书房等你。他没有表现出敌意，甚至亲手给你倒了茶。

“你现在是家里最大的股东之一。但公司不是银行账户，不能想怎么动就怎么动。给我一点时间，我把业务慢慢交给你。”

财务总监陈总坐在旁边，没有插话。他的公文包里放着一份尚未提交董事会的现金流报告。

选项：
- 亲自接管企业，组建自己的管理团队。
- 暂时信任叔叔，先熟悉企业经营。
- 聘请专业团队，进行全面审计。
- 先不急着管企业，给自己一段时间适应新生活。

设计约束：不能把任一选项标成正确。管理能力、叔叔可靠度、陈总立场、家族张力和市场阶段共同影响结果。

### 场景 2：一份不太好看的报表

几天后，公司的现金流问题浮出水面。报告显示，几笔大额应收款已经逾期，部分项目的回款时间还在继续推迟。

如果此前启动审计，陈总会更愿意私下提供细节；如果此前信任叔叔，他可能先替叔叔解释；如果此前暂缓接手，董事会开始追问你是否愿意承担股东责任。

选项：
- 让陈总独立核对现金流，先查清事实。
- 召开董事会，把问题摆到台面上。
- 先压下消息，观察一周再决定。
- 让叔叔提出处理方案，自己暂不介入。

### 场景 3：阿杰的电话

多年没见的老友阿杰听说你继承了家族资产，约你见面。他正在做一个小项目，想请你投资。

他没有开口就谈几千万，只说：“我知道你现在有钱，但我更想知道，你愿不愿意相信我一次。”

选项：
- 直接投资，和朋友一起承担风险。
- 先看项目和账目，再决定是否合作。
- 不投资，但愿意帮他介绍资源。
- 暂时不回应，先处理自己的事情。

设计约束：阿杰真诚不代表项目必然成功；谨慎也不代表不重情义；拒绝投资不等于失去友情。

### 随机与延迟事件池

- 叔叔重新评估：回应玩家接管企业或信任叔叔的决定。
- 审计线索浮现：只在启动审计后具备触发资格。
- 合作窗口关闭：连续回避投入与合作后，机会转向其他人；玩家可选择小规模试点，或接受机会流失。
- 媒体偶遇：外界关注达到条件后才可能出现。
- 陈总的私下提醒：关系与审计状态满足时可能出现。
- 老同学聚会：高关注度下出现新的社交机会，也可能带来利益请求。

随机事件只在条件满足时抽取，同种子与相同选择序列必须可复现。

## 第一章阶段性结果

v0.1 首版只验证第一章结束时的人生走向，不将其冒充为整个人生终局。阶段性结果至少覆盖：

- 真正开始掌舵：获得实际控制权，也开始承担经营责任。
- 被家族关系牵制：资产在手，决策权却迟迟没有到来。
- 选择自己的生活：不让家族企业成为人生唯一中心。
- 与朋友共同起步：在新的事业关系中找到不同方向。
- 进退之间：局势尚未明朗，留下继续体验的空间。

完整版本再扩展为 8–12 个经过完整主线验证的终局。
